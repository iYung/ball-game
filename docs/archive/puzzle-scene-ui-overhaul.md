### Shared contracts (every task relies on these exact shapes)

- Commands: `"up" | "down" | "left" | "right" | "stop"`. There is no `"idle"` any more.
- Timeline data (scene field `self.timeline`): `self.timeline[lane][tick] = { pusher = <int id, 1=A>, cmd = <command> }`, lane 1..4, tick 1..60. Constants `Timeline.LANES = 4`, `Timeline.MAX_TICKS = 60`.
- Pure module `lua/game/timeline.lua` (Task 1) owns that data; the scene never pokes the tables directly.
- Sim input (Task 2): `st.commands` is the list `{ {pusher=id, cmd=cmd}, ... }` for the **current tick** (the sim does not know about lanes). Each pusher table has `id` and a persistent `dir` (nil/"stop" = not moving). `Sim.advance(st, commands)` increments `st.tick`, applies the commands to `p.dir`, then runs the unchanged push physics using `p.dir`. Pusher keeps `dir` when blocked by wall/gap/pusher.
- Ids in `ui_elements()`: ops column `palette:<name>` (existing ids kept), pusher selector `psel:<letter>`, instruction chips `chip:<cmd>`, timeline cells `slot:<lane>:<tick>`, timeline scroll `tl:scroll_left` / `tl:scroll_right`, run controls `cmd:run|reset|menu|continue` (unchanged).
