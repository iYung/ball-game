# Settings Modal Checklist

## Group A — Foundation (sequential; each depends on the prior)

- [x] Task A1 — `lua/core/sound.lua` — Create the Sound module. Two module-level variables (`_sfx_volume = 1`, `_music_volume = 1`). Two public functions: `Sound.set_sfx_volume(v)` clamps `v` to [0,1] and stores it; `Sound.set_music_volume(v)` does the same. No `love.audio` calls yet — just store the values so `SettingsState` has something to call. Return the module.

- [x] Task A2 — `lua/core/save.lua` — Create the Save module with a Lua-serialiser (port the `serialize` local function from `/root/wip/lua/core/save.lua` verbatim). Expose four functions: `Save.settings_exist()` → `love.filesystem.getInfo("settings.dat") ~= nil`; `Save.write_settings(data)` → writes `"return " .. serialize(data)` to `settings.dat`; `Save.read_settings()` → loads and returns the table or `nil` on error (use `loadstring or load` for Love 5.1/JIT compat). Also add stubs `Save.exists()`, `Save.write(data)`, `Save.read()` operating on `save.dat` (same pattern) so future save-game work has a home.

- [x] Task A3 — `lua/game/settings_state.lua` — Create SettingsState. Fields: `sfx_volume` (0–100, default 100), `music_volume` (0–100, default 100). Methods: `SettingsState.new()`, `SettingsState.from_save(data)` (reads `sfx_volume` and `music_volume` numbers from table, falls back to defaults for missing/invalid fields), `state:set_sfx_volume(v)` (clamps to [0,100], stores, calls `Sound.set_sfx_volume(v/100)`), `state:set_music_volume(v)` (same pattern), `state:to_save()` (returns `{sfx_volume=…, music_volume=…}`). Requires `lua/core/sound` and `lua/core/save`.

- [x] Task A4 — `lua/game/scenes/settings_menu.lua` — Create the SettingsMenu overlay. **Not a Scene subclass** — a plain table with `is_open = false`. Constructor: `SettingsMenu.new(settings_state, scene_manager)`. Rows (numbered 1–4): 1 = SFX Volume, 2 = Music Volume, 3 = Resume, 4 = Exit to Menu. `open()` sets `is_open = true`, `selected = 1`, snapshots `_prev_up/_prev_down/_prev_left/_prev_right/_prev_confirm/_prev_escape` from current keyboard state so held keys don't fire. `close()` sets `is_open = false`. `update(dt)`: reads `love.keyboard.isDown` for up/down/left/right (WASD + arrows)/space+return/escape, edge-detects with `_prev_*` flags, navigates rows, adjusts volume by 10 on left/right for rows 1–2, calls `_on_confirm()` on space/return, calls `close()` on escape. `_on_confirm()`: row 3 → `close()`; row 4 → `Save.write_settings(settings_state:to_save())` then `scene_manager:switch(StartScene)`. `key_pressed(key)`: handle `escape` → `close()`; `return`/`space` → `_on_confirm()`; `left`/`a` and `right`/`d` for volume rows; `up`/`w` and `down`/`s` for navigation. Returns `true` if the key was consumed. `draw()`: dark semi-transparent overlay (`setColor(0,0,0,0.6)` rect over 1280×720); centred panel (white rect 400×300); title "Settings" at top; four rows with label + value/action text; selected row highlighted in a different colour; left/right arrow hints on volume rows. Register rows 1–4 as ui_elements with ids `settings:sfx`, `settings:music`, `settings:resume`, `settings:exit`. Add `mouse_pressed(mx, my)` that hit-tests through `UI.element_at` and acts accordingly.

## Group B — Wiring (sequential; depends on Group A being complete)

- [ ] Task B1 — `main.lua` — At the top of `love.load()`, before `manager:switch(...)`: require `SettingsState` and `Save`; call `SettingsState.from_save(Save.read_settings())` to get a singleton `settings_state` local. Pass it to `StartScene.new(manager, settings_state)`. Update `StartScene.new` signature to accept and store `settings_state` (no other StartScene changes). Pass `settings_state` down when StartScene creates LevelSelectScene, and LevelSelectScene passes it when creating MatrixScene. *(Each scene change is small — a constructor arg stored as `self._settings_state` and forwarded on switch.)*

- [ ] Task B2 — `lua/game/scenes/level_select_scene.lua` — Accept `settings_state` as second constructor arg (after `scene_manager`). Store as `self._settings_state`. In `on_enter()`, construct `self._settings_menu = SettingsMenu.new(self._settings_state, self.scene_manager)`. In `update(dt)`, if `self._settings_menu.is_open` call `self._settings_menu:update(dt)` and return early. In `key_pressed(key)`, if `self._settings_menu.is_open` check `self._settings_menu:key_pressed(key)` and return if consumed; else if key == `"escape"` call `self._settings_menu:open()` (instead of switching to StartScene). In `mouse_pressed`, if overlay is open delegate to `self._settings_menu:mouse_pressed(...)`. In `draw()`, call `self._settings_menu:draw()` after the existing draw. Forward `settings_state` when constructing MatrixScene.

- [ ] Task B3 — `lua/game/scenes/matrix_scene.lua` — Accept `settings_state` as a constructor arg (look for `MatrixScene.new` and add it). Store as `self._settings_state`. In `on_enter()`, construct `self._settings_menu = SettingsMenu.new(self._settings_state, self._scene_manager)`. In `update(dt)`, if overlay is open call `self._settings_menu:update(dt)` and return early. In `key_pressed(key)`, if overlay open delegate first; else if key == `"escape"` call `self._settings_menu:open()` (instead of switching to LevelSelectScene). In `draw()` call `self._settings_menu:draw()` last. *(Other MatrixScene logic is unchanged.)*
